# Implementation Gaps

Date: 2026-07-17

This file is intentionally adversarial. A dry run proves serialization and routing; it does not prove the claimed capability is scientifically isolated.

## Blocking

| Gap | Affected Conditions | Evidence | Why It Blocks |
| --- | --- | --- | --- |
| Paid execution is disabled | all paid conditions | `scripts/longmemeval_full/run.py:75-79` | Correctly prevents accidental spend, but no paid pilot can run until explicit reader/judge wiring and cost review are added. |
| `waggle_agentic_mcp` is deterministic simulation, not model-selected tool use | `waggle_agentic_mcp` | `scripts/longmemeval_full/conditions.py:366-425` | It calls `prime_context`, `query`, then optionally `get_related` in fixed order. It does not expose tool schemas to a reader model or let the model choose calls. |
| `waggle_hybrid_no_edges` does not disable HybridRetriever's internal graph-expansion layer | `waggle_hybrid_no_edges`, `waggle_hybrid_with_edges` | `scripts/longmemeval_full/conditions.py:316-381`; `src/waggle/retrieval/hybrid.py:241-247` | The no-edge adapter suppresses returned edge context and uses `expand_depth=0`, but production hybrid retrieval still computes graph-expansion candidates internally. Claims about edge contribution are not clean yet. |
| Temporal ablation is too coarse | `waggle_context_without_temporal_resolution`, `waggle_context_with_temporal_resolution` | `scripts/longmemeval_full/conditions.py:237-249`; `src/waggle/recursive_context.py:299-305` | The current no-temporal mode only disables `conflict_resolve` in `build_context`. It does not separately disable all `valid_from`, `valid_to`, `updates`, `contradicts`, and source-authority logic. |
